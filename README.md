# Riskora

> Security visibility and threat detection for small businesses.

Riskora is a SaaS platform designed to help small and growing businesses
understand their security posture, monitor suspicious activity and receive
security alerts when potential threats are detected.

## 🚧 Project Status

Currently under active development.

The project is currently focused on building the first security assessment MVP.

## 🔐 Security Philosophy

Riskora is designed primarily as a security visibility and monitoring platform.

It does not attempt to replace WAFs, firewalls, EDRs or dedicated security teams.

The initial platform focuses on passive/public security assessment,
monitoring, detection and alerting.

Riskora should never actively exploit systems without explicit authorization.
