RISKORA — DEVELOPMENT ROADMAP
================================

PRODUCT GOAL
------------
Build a SaaS platform that allows small and growing businesses to:

1. Assess their public security posture.
2. Continuously monitor their digital assets.
3. Detect suspicious activity and possible attacks.
4. Group activity into incidents.
5. Alert the responsible team.
6. Provide context and recommended actions.

Core product evolution:

Security Scanner
       ↓
Security Monitoring
       ↓
Threat Detection
       ↓
Incident Management
       ↓
Security Intelligence

==================================================
PHASE 21 — DETECTION ENGINE
==================================================

Build rule-based detection first.

Do NOT start with AI.

Initial detections:

1. Brute-force
2. Credential stuffing
3. Path enumeration
4. Reconnaissance
5. SQL injection patterns
6. XSS patterns
7. Bot/traffic anomaly
8. Authentication anomaly
9. DNS change
10. Certificate change

Example:

100+ failed logins
+
same source/network
+
short time window
=
Possible brute-force detection


IMPORTANT:
Use language such as:
"Suspicious activity detected"
"Possible brute-force attack"

Do not claim:
"You were hacked"

unless there is sufficient evidence.
